# AJAX-App
It's time to put everything together! You will use all the concepts covered so far—SASS, AJAX, the template element, and the Fetch API—to make the Earbuds Model Page dynamic. An API link will be provided, outputting information about the earbuds in JSON format.

## Installation
There is no installation process required. Simply download the files to your computer.

## Usage
Open index.html in your browser of choice.
